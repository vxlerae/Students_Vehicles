# Student Vehicle Information Program

## Overview

This Java program collects information about a student and their vehicle, then displays a summary of the details.

---

## Features

* Takes user input for student and vehicle details
* Creates objects for `Student`, `Vehicle`, and `Car`
* Displays a formatted summary of the owner and their car

---

## How It Works

* Prompts the user to enter personal and vehicle information
* Instantiates objects using the provided input
* Outputs a descriptive summary using `toString()` methods

---

## Dependencies

* `Student`
* `Vehicle`
* `Car`

---

## Author

Created as a Java exercise for object-oriented programming and user input handling.
